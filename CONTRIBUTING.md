# Contribuindo

Comece pelo [guia de desenvolvimento](docs/development-guide.md). Trabalhe em branches como `feat/perfil`, `fix/cors-local` ou `docs/contrato-vagas`. Use Conventional Commits, por exemplo `feat(api): define contrato de perfil`.

Abra PR contra `main` e peça revisão à equipe da camada afetada. Alterações de contrato que afetam ambas as aplicações devem ser revisadas pelas duas equipes. No GitHub, a configuração proposta para `main` exige PR, uma aprovação e os checks `web` e `api`.

Use o checklist do [template de PR](.github/pull_request_template.md). Execute os comandos do guia antes de solicitar revisão.
